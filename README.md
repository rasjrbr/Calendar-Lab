# Calendar Lab

**A schedule companion for LATAM Airlines Brasil Captains, on iPhone.**
Calendar Lab turns the iFlightNeo roster into a clean, enriched calendar with duty limits, Home and Airport Standby rules, Red Eye rules and rest alerts. Everything is processed on the device: no servers, no account, no ads, no tracking.

> This repository hosts the app's **public website and legal documents** only. The app's source code is private.

### Maintaining this site

- Plain static HTML served by GitHub Pages from the `main` branch root. `.nojekyll` turns off Jekyll processing.
- All internal links are relative, so the site works unchanged at `rasjrbr.github.io/Calendar-Lab/` or at a future `calendar-lab.github.io/`. Only the absolute links in this README and in `404.html` (which GitHub serves at any missing path, so it cannot use relative links) would need updating.
- Portuguese pages are at the root and are the governing text. English pages are in `en/`. Keep both in sync and update the "Last updated" date on any legal change.
- The contact email appears in every page. To change it, replace `asdumont@gmail.com` across all files.
